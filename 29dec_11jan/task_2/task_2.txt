Задача 2 - Паттерны проектирования Темы: Design Patterns, Builder, Decorator, ООП, абстрактные классыОписание задачи:
Необходимо создать систему для конфигурации и постройки сложного объекта HTTP запроса с использованием паттерна Builder и паттерна Decorator для добавления логирования и валидации.Часть 1: Builder Pattern
Создайте класс HTTPRequest с параметрами: URL, метод (GET/POST), заголовки, тело запроса, timeout
Реализуйте HTTPRequestBuilder для пошагового создания запроса
Методы: set_url(), set_method(), add_header(), set_body(), set_timeout(), build()
Часть 2: Decorator Pattern
Создайте декоратор LoggingDecorator для логирования всех операций с запросом
Создайте декоратор ValidationDecorator для валидации URL и заголовков
Оба декоратора должны быть составляемыми (можно применять несколько)
Критерии:
Правильная реализация паттерна Builder
Правильная реализация паттерна Decorator (минимум 2)
Возможность комбинирования декораторов
Обработка ошибок при неправильных параметрах
Примеры использования обоих паттернов
Unit тесты (минимум 5)
Код должен быть хорошо отформатирован и задокументирован
Необходимы комментарии к каждой строчке кода, что и где выполняется
