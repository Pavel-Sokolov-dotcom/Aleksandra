Задача 1 - Система управления студентами  Темы: Основы ООП, классы, методы, структуры данных
Описание задачи:
Необходимо создать систему управления студентами и их оценками. Программа должна создавать объекты студентов с атрибутами: имя, ID, список предметов и оценок. Добавлять и удалять предметы. Добавлять оценки по предмету. Рассчитывать средний балл по всем предметам. Выводить информацию о студенте в понятном формате. Сохранять данные в JSON файл и загружать их обратно.
Критерии:
Класс Student с атрибутами
Методы: add_subject(), remove_subject(), add_grade(), get_gpa(), __str__()
Корректная работа со всеми методами
Обработка исключений (удаление несуществующего предмета, некорректные оценки)
Файл students.json с примером данных (минимум 3 студентов)
Код должен быть хорошо отформатирован и задокументирован
Необходимы комментарии к каждой строчке кода, что и где выполняется.
